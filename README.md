# 📌 Project Overview

This repository contains the development of the **Next Level Gaming & Esports Arena** website.

The website was developed using HTML, CSS, and JavaScript to provide users with information about gaming packages, esports services, contact details, and an interactive fee calculation system.

---

# 🎯 Project Goals & Objectives

1. Create a professional and responsive website.
2. Showcase gaming and esports services.
3. Provide package information in an organized format.
4. Implement user-friendly navigation.
5. Calculate package fees automatically.
6. Apply discount rules and VAT calculations.
7. Validate user input.
8. Demonstrate web development skills using HTML, CSS, and JavaScript.

Open the project folder in Visual Studio Code.
